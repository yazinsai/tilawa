## Mechanism

`packages/sdk/src/response-fingerprint.ts` replays the unchanged primary streaming graph with independent recurrent state. Two fixed smooth spectral patches, centered at 0.28 and 0.72 of the mel axis with width 0.2, receive symmetric ±0.05 log-mel interventions in a nine-frame temporal patch centered at input frame `4*t+3`. Each intervention starts from the identical incoming baseline caches. Perturbed outgoing states are discarded, and baseline outputs and states are copied before another invocation can reuse their buffers. Only requested warning rows require the four extra graph calls; baseline replay supplies the original context and clock.

The response feature concatenates both signed finite differences of centered phone logits, retaining direction and relative phone response. Centered log probabilities equal centered pre-softmax logits, so this requires no ONNX graph surgery. The unperturbed control concatenates centered logits from the current and preceding output rows. Both arms have exactly twice the vocabulary dimension and use the same model capacity, regularization and boundary topology. Unsupported sample rate, mel geometry or output clock fails explicitly.

`modal/student_response_fingerprint.py` fits full-Gaussian phone emissions, including blank, with transcript-conditioned soft boundary occupancies. Parent posteriors initialize the occupancies; four EM iterations then marginalize boundaries under each arm's own fitted acoustic likelihood. Complete CTC paths are required, repeated identical labels need blank separation, and the shared timing prior is conditioned on completion to avoid rewarding pronunciation path counts. Unsupported training phones abstain at inference.

Only usable help-train training-speaker `none` takes without labelled mistakes or repeats enter extraction. The preparation CLI excludes explicit speakers and any speaker appearing in nontraining labels. The trainer independently checks source, kind, split, exclusion, primary checksum and the shared extraction deadline. The label-field contract was checked against `tools/help_import.py`; the actual supplied recordings have not been inspected. Release-held-out speakers are absent from the supplied training copy by the task's contract, and an explicit exclusion list is also required.

Three folds group by speaker. The fixed regularization grid is 1, 16 and 64; one shared value minimizes the mean of both arms' conditional phone-identity validation losses, weighting speakers equally. Training-only preservation diagnostics compare actually recorded `none` pronunciations against deterministic single-phone lexical counterfactual references. They do not select regularization and do not establish preservation of verified scripted substitutions. Neither practice windows nor their labels influence extraction geometry, fitting or selection.

Extraction caches each completed recording and freezes a common deadline no more than one day away; resumes cannot restart it. The trainer enforces that same deadline. Export copies the primary bundle to a new directory without changing the primary graph, manifest or existing auxiliary bytes, writes the fitted emissions and hashed asset declaration, and records all copied file hashes.

## Product integration

Core exposes otherwise supported string-path wrong-word comparisons using their exact existing frame intervals and complete written/rival sequences. The SDK scores both pronunciations on identical response/control rows and transports a certificate only for finite strict opposing preferences. Certificates match word identity, both strings and both frame bounds. Ties, insufficient observations and unseen phones abstain.

The public verdict alone can become uncertain. The internal confirmation/ownership ledger remains unchanged, preserving insertion merges and subsequent candidate generation. Graph confirmations are exempt. Primary decoding, posterior rows and tracker input are preserved. Audio sessions retain certificates in recorded evidence and publish end-of-session downgrades only for exact live occurrences removed by an identical-primary-evidence replay. The live checker must also have identified that occurrence as a supported string-path confirmation, so a different replay interpretation cannot retract a live graph confirmation; repeated words and later graph confirmations cannot be retracted by spelling alone.

The Node loader verifies the emissions file's declared byte count and SHA256, the actual primary checksum, fixed perturbation metadata and Gaussian geometry. Missing, corrupt or orphan fitted files fail rather than silently disabling the scorer. A declared fingerprint bundle with the current Quran inventory must also retain the existing insertion teacher. The response backend uses the same primary graph in a separate runtime and is released with the primary backend.

This implementation buffers audio and reviews at `end()`. It does not establish timely suppression of already published streaming warnings, bounded session memory, mobile loading, or device latency. Signed finite differences through the shipped quantized graph may reflect quantization steps rather than useful phonetic response; that remains an acoustic premise to test.

## Mechanism

The card describes a retained near continuation losing to the rhyme restart by 0.3915 edits. Independent duration costs cannot express whether adjacent sounds shorten and lengthen together. This prototype adds a Gaussian Markov copula over pronunciation-conditioned duration residuals. Its independent control uses exactly the same lognormal marginals; setting every correlation to zero makes the contribution exactly zero, including alternative insertions, deletions and jumps.

`tracker.ts` forwards each token's emitted-run length to the local search. `local.ts` retains the existing 16-observation horizon, including speech before a restart, and rewinds those observations with its saved search state. Only a proposed run-origin change after a full horizon invokes `rhythm.ts`. Both partitions replay the same observed tokens over the same original reference/edit/movement graph, seeded with the same pre-horizon costs. The score contribution is −log(Z_joint/Z_independent), converted to the existing local edit units. Every candidate cell receives its own contribution before selection. The original edit costs, jump distances, available movement edges and reporting margins remain unchanged; checker handling is unchanged.

The duration vector is log transformed and centered on its common geometric mean, so a common change of speaking rate cannot change the contribution. Structural classes distinguish short vowels, held vowels, ordinary and lengthened nasals, sonorants, fricatives and stops/other sounds; insertions have a separate background class. No word, verse, reader or session identity enters runtime parameters.

`rhythm-fit.py` is a training-only estimator. It requires explicit training-speaker, none-labelled help-train recordings, excludes labelled mistakes and repeats, and excludes any speaker marked held out anywhere in the supplied labels. It refuses absent decodes or an unavailable training split. Transcript-conditioned edit forward/backward supplies soft token-to-phone correspondence, including deletions between adjacent emissions. Three speaker-grouped folds select class-pair correlation pooling from the predeclared strengths 10, 100 and 1000. The matched independent control shares all duration parameters. The final report hashes the reference, selected labels and decoded observations; runtime output contains only fitted numeric parameters.
